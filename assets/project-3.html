County Data Regression¶

Andrew Morgan¶

Regression is a general task in machine learning that involves predicting continuous values for unseen examples given sets of features for training examples. This project takes a look at a number of regression experiments (involving various models and selected feature sets) with American country data; that is, any data related to the socioeconomic state of the county (industry, population, crime, etc.). The overall goal is to investigate the prediction of the poverty level of a county based on some feature(s) to gain an understanding of what factors cause poverty across American counties. I hypothesize that many factors and likely some not represented in the dataset will be responsible for the poverty level - in addition, the reduction of counties to a set of data points often loses the context surrounding the county. Still, an investigation of the causes of poverty may go a long way to alleviating it.

I'll be using evangambit's JsonOfCounties dataset from GitHub: https://github.com/evangambit/JsonOfCounties/tree/master. This dataset cites all of it's sources and appears reputable and well-maintained.

Experiment 1: Linear Regression Modeling and Evaluation¶

First, I'll try an ordinary multiple linear regression, which is a good starting place when doing regression over more than one input feature. Multiple linear regression finds the weights of a linear equation that best fits (yields the lowest error on) the training data. Multiple linear regression does not require gradient descent or any parameter estimation method, as the best weights are found through an analytical solution, which is derived by setting the derivative of the training error (mean squared error) to zero and solving for w. Since the mean squared error function is convex, it only has one global minimum, and hence setting the derivative equal to zero and solving for the weights will yield the weights when the error is at the global minimum.

$$MSE: \frac{1}{2N}\sum_{n=1}^{N}({y_{n, pred}-y_{n, true}})^{2}$$$$w_{optimal} = (X^{T}X)^{-1}X^{T}y$$
In [263]:
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error as mse
from sklearn.metrics import root_mean_squared_error as rmse

lr_model = LinearRegression(fit_intercept=True)
lr_model.fit(X_train, y_train)
print(f"R^2: {lr_model.score(X_test, y_test)}")

R^2: 0.6620523972713697

R^2 is also known as the "coefficient of determination", and it tells you how much of the change in y is explained by X. In our case, about 62% of the variation in the rate of poverty is explained by the four features we chose (% smokers, % physically inactive, food environment index, and % excessive drinking).

In [265]:
y_pred_Train = lr_model.predict(X_train)
print(f"Train MSE: {mse(y_train, y_pred_Train)}, Train RMSE: {rmse(y_train, y_pred_Train)}")  # RMSE is the normalized MSE.
y_pred_Test = lr_model.predict(X_test)
print(f"Test MSE: {mse(y_test, y_pred_Test)}, Test RMSE: {rmse(y_test, y_pred_Test)}")

Train MSE: 12.970763392047385, Train RMSE: 3.601494605305884
Test MSE: 11.827284286929755, Test RMSE: 3.439081895932366

It looks like our model predicts the target feature well, and also generalizes to unseen examples well, as the testing loss is similar to the training loss.
