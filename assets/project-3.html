County Data Regression¶

Andrew Morgan¶

Intro + What is regression?¶

Regression is a task in machine learning that involves predicting continuous values for unseen examples given sets of features of training examples. This project takes a look at a number of regression experiments/techniques with American country data; that is, any data related to the socioeconomic state of the county (industry, population, education rate, etc.). The overall goal is to investigate how we can predict the poverty level of a county based on other county feature(s) to gain an understanding of what factors cause poverty across American counties. I hypothesize that a large number of factors, and likely some not represented in the dataset, will be responsible for the poverty level. Still, an investigation of the causes of poverty may go a long way towards alleviating it.

I'll be using evangambit's JsonOfCounties dataset from GitHub: https://github.com/evangambit/JsonOfCounties/tree/master. As mentioned, it contains several socioeconomic features of all counties in America. This dataset cites all of it's sources and appears reputable and well-maintained.

Experiment 1: Linear Regression Modeling and Evaluation¶

What is regression?, continued in greater detail:¶

First, I'll try a simple multiple linear regression using ordinary least squares. Multiple linear regression finds the weights of a linear equation ($y = mx + b$, or $J_{W}(x) = w_{1}x + w_{0}$) that best fits (yields the lowest error on) the training data. Multiple linear regression does not require gradient descent or any parameter estimation method, as the best weights are found through an analytical solution (known as ordinary least squares), which is derived by setting the derivative of the training error (mean squared error) to zero and solving for w. Since the derivative of the mean squared error function is convex, it only has one global minimum, and hence setting the derivative equal to zero and solving for the weights will yield the weights when the error is at the absolute minimum.

$$MSE: \frac{1}{N}\sum_{n=1}^{N}({y_{n, pred}-y_{n, true}})^{2}$$

where the prediction is: $$y_{n, pred}=w^{T}x_{n}$$ for some example feature vector $x_{n}$. The optimal weights found through setting the derivative of the mean squared error formula to zero and solving for w are: $$w_{optimal} = (X^{T}X)^{-1}X^{T}y$$

Scikit-learn's LinearRegression class uses ordinary least squares to fit the model to the data.

Evaluation¶

I'll use R^2 (explained below), MSE (explained/defined above), and root MSE (RMSE), which takes the square root of the MSE to normalize it to the units of the target feature (in our case, to the poverty rate).

R^2 is also known as the "coefficient of determination", and it tells you how much of the change in y is explained by X. In our case, about 62% of the variation in the rate of poverty is explained by the four features we chose (% smokers, % physically inactive, food environment index, and % excessive drinking).

Experiment 2: Principal Component Analysis (PCA): Good Idea?¶

Principal component analysis (PCA) is a dimensionality reduction technique that allows for high-dimensional data (with a large number of features) to be distilled into one or two (or any small number) of features. Though PCA is intended to distill a large number of features into a much smaller number, I'm curious how the technique will affect our scenario (where there are only four input features). Hopefully, it will at least provide a way of directly visualizing the data, impossible with four-dimensional data.

It looks like PCA is not going to be a good option here. The correlation between input and target features is much weaker after using PCA than it was in our original data. It looks like almost half of the information in our original features was lost when reducing to one-dimensional data. Let's confirm this by training a linear regression model using our PCA data:

As suspected, the MSE and RMSE are much higher across the board than it was with the original four features. The R^2 is also nearly halved, showing that much less of the change in y is explained by the change in X. This experiment highlights the limits of PCA: that it is not always a viable option when looking to improve or visualize a regression experiment. Often, it can end in a massive loss of information, as seen here. PCA seems particularly useful or worthwhile only when the number of features is very high, much higher than the four used here.

Impact¶

As mentioned in the introduction, a strong understanding of what factors contribute to changes in the poverty rate of counties across America is essential to combating poverty. Predicting the poverty rate using a regression model may become relevant if the poverty rate is ever unavailable for a county, or if the Census Bureau (the organization responsible for calculating the poverty rate used in this dataset) ever intends to re-examine how they determine the value. According to https://www.census.gov/programs-surveys/saipe/technical-documentation/methodology.html, this methodology is revisited occasionally.

A potential negative impact of my methodology is that it may, to some extent, decontextualize the county's situation regarding poverty. Not all the information that explains a county's poverty level is available, and possibly not all of it can even be quantified, so this project is reductive in that sense. Furthermore, it could be incorrectly construed that some feature causes poverty completely or nearly completely, when really it is only one of many factors correlated with poverty. I don't wish to create the harmful stereotype that, for example, a low education rate guarantees a high poverty rate. Correlation is not causation!

Conclusion¶

I've analyzed and identified several socioeconomic features that statistically correlate with the poverty rate in American counties, finding that health/lifestyle metrics, education level, and cost of living together are significant explainers of poverty through regression experiments and visualizations. Not that there are many features left in the full dataset to try; I've chosen ones that I hypothesized would've helped explain poverty.

I also tried principal component analysis (PCA) on the health/lifestyle features I used in my first experiment, finding empirically that PCA was a poor choice for that scenario, likely due to the relatively small number of initial features. I've come away with a greater understanding of when to consider using PCA, and how to determine the effect it's having on a dataset.

Zooming out, I've learned a lot about feature selection in regression experiments, regression metrics (R^2, MSE/RMSE), and techniques of visualizing/understanding continuous data (e.g., PCA).
